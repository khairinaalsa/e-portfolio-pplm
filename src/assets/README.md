# 📷 Folder Foto E-Portfolio

Letakkan foto Anda di folder ini dengan **nama file persis** seperti di bawah.
Foto akan otomatis terpasang di website (tidak perlu mengubah kode apa pun).

| Nama file            | Digunakan untuk                                   | Saran ukuran           |
| -------------------- | ------------------------------------------------- | ---------------------- |
| `foto-profil.jpg`    | Foto profil di halaman **Profil Guru** + avatar    | Potret (3:4), maks 1200px |
| `foto-beranda.jpg`   | Background **Beranda** (suasana mengajar/kelas)    | Lanskap (16:9), maks 2000px |
| `foto-kegiatan.jpg`  | Banner **Kegiatan Nonmengajar** (bersama siswa)    | Lanskap (16:9), maks 2000px |

Ekstensi yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp`

Contoh:

```
src/assets/foto-profil.jpg     <- foto wisuda Anda
src/assets/foto-beranda.jpg    <- foto bersama siswa di halaman sekolah
```

## Cara cepat tanpa menyalin file

Buka website, klik tombol **📷 Foto** di pojok kanan bawah, lalu unggah foto
langsung dari perangkat Anda. Foto akan otomatis diperkecil dan tersimpan di
browser. Cara ini praktis untuk pratinjau, namun agar foto ikut terbawa saat
website dibagikan/di-hosting, gunakan cara menyalin file ke folder ini.
